# Dicta releases

Public download + auto-update feed for **Dicta**, a private macOS dictation app.
Only finished builds live here; the source code is private.

- **Install:** download the latest `Dicta-x.y.zip` from [Releases](../../releases), unzip, drag to Applications. First launch: right-click the app → **Open** (one time).
- **Updates:** after that first launch, Dicta updates itself automatically.
